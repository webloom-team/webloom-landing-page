FAQ

Pertanyaan yang biasanya muncul sebelum mulai.

Jawaban di bawah mengikuti cara kerja Webloom saat ini. Jika ada yang belum tercakup, tanyakan langsung lewat WhatsApp.

Tanya hal lain
Berapa lama pengerjaannya?

Paket 01 biasanya selesai dalam 3–5 hari kerja. Paket 02 membutuhkan 5–7 hari kerja. Hitungan dimulai setelah materi dari Anda lengkap.

Berapa kali saya bisa revisi?

Setiap paket mendapat kuota 3 kali revisi desain atau konten.

Bagaimana skema pembayarannya?

DP 50% di awal, lalu pelunasan 50% setelah pekerjaan selesai dan sebelum website live.

Apakah ada biaya bulanan untuk CRM?

Tidak ada biaya software bulanan dari Webloom untuk akses CRM pada Paket 02.

Bagaimana dengan biaya hosting dan domain?

Hosting dan domain dibayar terpisah oleh klien. Anda bisa mencari dan mengurusnya sendiri, atau menyerahkan pengurusannya kepada Webloom.

Apakah source code menjadi milik saya?

Source code landing page menjadi milik Anda setelah pembayaran lunas.

Apa saja yang perlu saya siapkan?

Logo, deskripsi bisnis, foto, daftar produk atau layanan, kontak, dan materi pendukung lain.

Bisa upgrade dari Paket 01 ke Paket 02?

Bisa. Anda cukup membayar selisih Rp300.000, dengan ketentuan yang disepakati saat konsultasi.
